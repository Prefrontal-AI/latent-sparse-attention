# Data assembly

Some of the data this repository reads cannot be redistributed, because its text carries licences of its own.
This directory holds what a reader needs to assemble it themselves, and the generators in `src/lsa` do the work.

| Dataset | What this directory holds | Licence of what is here |
|---|---|---|
| [LongDocs](longdocs) | how to collect its public sources from the hub and check them against a lock file | no text; the sources keep their own licences |
| [PaperTrail](papertrail) | the benchmark's definition, its questions and answer keys, and how to rebuild it from arXiv | CC BY 4.0 |

The papers, documents and code the datasets are made of keep the licences their owners gave them, and are fetched from where they are published.
Each dataset's directory says what it holds and under which licence.
